### 🎯 الفكرة | Concept

**نبض (NABDH)** هي منظومة ذكية للكشف المبكر عن التهديدات البيولوجية والغذائية باستخدام:
- **محرك مرجان (CHIMERA Engine):** محرك ذكاء اصطناعي متعدد الرؤوس للكشف
- **بلوكتشين نبض:** لتوثيق غير قابل للتزوير لسلسلة الإمداد الغذائي
- **الدفاع الموحد:** Many Heads, One Defense

### 🧬 المكونات

| الملف | الدور |
|-------|-------|
| `chimera_engine.py` | قلب المنظومة - محرك الكشف البيولوجي |
| `chimera.py` | واجهة مرجان الرئيسية |
| `blocktchaine.py` | سلسلة كتل نبض للأمن الغذائي |
| `test/` | اختبارات المنظومة |
